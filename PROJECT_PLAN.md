# CareerTrack

Student Job & Internship Management Platform

## Purpose

CareerTrack helps students manage job and internship applications,
interviews, resumes and career progress in one place.

## Main Features

- User registration and login
- Job/internship application tracking
- Interview tracking
- Company management
- Resume management
- Career dashboard
- Career analytics
- Job description analyzer

## Technologies

Frontend:
HTML, CSS, JavaScript

Backend:
Python, Flask

Database:
SQLite

Version Control:
Git and GitHub

Future:
Machine Learning based job description analysis
